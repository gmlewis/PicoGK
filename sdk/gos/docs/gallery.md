# Gallery

Parametric shape examples built with the Gossamer PicoGK SDK.

The scenes are generated by the [`ffi-gallery` example](../examples/ffi-gallery/),
which uses the FFI SDK (`picogkffi`) and the `picogkshapes` parametric shape
library — a direct port of PicoPie's `picogk.shapes`. Rendering uses the
native OpenGL Viewer (PBR shading), matching PicoPie's output.

```bash
cd examples/ffi-gallery
RUSTFLAGS="-Awarnings" gos run --no-jit .   # render every scene (requires display)
```

## Notes

The `ffi-gallery` example uses the `picogkshapes` package — a Gossamer port
of PicoPie's `picogk.shapes` parametric shape library — so the gallery scenes
match the Python output closely (modulated radii, swept spines, gyroid
infill, etc.).

Surface smoothness is set by the voxel size (passed to `init`), not the
parametric tessellation: every scene is rasterised to a voxel field and
re-meshed at that grid, so a coarse grid gives faceted silhouettes.
