# Gallery

Parametric shape examples built with the MoonBit PicoGK SDK, rendered via
`render_to_image` (headless isometric PNG with Lambertian shading).

The scenes are generated by the
[`shapekernel-gallery` example](../examples/shapekernel-gallery/).

```bash
cd examples/shapekernel-gallery
moon run .                # render every scene
```

## Notes

The MoonBit SDK exposes low-level MCP primitives (sphere, box, cylinder, torus,
capsule) rather than the high-level parametric shape library
(`picogk.shapes`) available in the Python binding. The gallery scenes are
approximated using the available primitives plus transforms and booleans.

Surface smoothness is set by the voxel size (passed to `picogk_init`), not the
parametric tessellation: every scene is rasterised to a voxel field and
re-meshed at that grid, so a coarse grid gives faceted silhouettes.
